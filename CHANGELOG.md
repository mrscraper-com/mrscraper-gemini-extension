# Changelog

All notable changes to the MrScraper Gemini CLI extension are documented here.
The project follows [Semantic Versioning](https://semver.org/).

## 0.1.0 - 2026-10-22

- Initial extension: the hosted MrScraper MCP server
  (`https://mcp.mrscraper.com/mcp`) with OAuth 2.1 sign-in, a `GEMINI.md`
  context file, and the `mrscraper`, `mrscraper-fetch`, and `mrscraper-serp`
  skills. Skills are identical to the MrScraper Claude plugin 0.2.2.
